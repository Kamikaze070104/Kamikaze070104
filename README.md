### 🌟 About Me

Hey there! I'm **Faizal Azzriel Gibar** 👋  
A passionate **Full-Stack Developer & Systems Software Engineer** and Computer Science / Software Engineering student at **Universitas Pendidikan Indonesia (UPI)**.

I specialize in building high-performance web platforms, interactive desktop applications, and concurrent backend services. Evolving from traditional web stacks, I now craft end-to-end solutions leveraging modern languages and frameworks such as **TypeScript, Next.js, React, Rust, Electron,** and **Tailwind CSS**.

- 🔭 **Currently Building**:
  - **[Pyromi](https://github.com/Kamikaze070104)** — Modern Desktop Video Editor powered by Next.js, Electron, Remotion, and Three.js.
  - **LemniDev Typst Studio** — High-performance real-time Typst document compiler & SaaS platform built with Rust (Axum, Tokio, gRPC) & React.
- ⚡ **Core Technologies**: TypeScript, Rust, Next.js, React, Node.js, Electron & Tailwind CSS.
- 🎯 **Areas of Interest**: High-Performance Web, Modern Desktop Apps, Distributed Systems & Creative Computing.
- 💬 **Ask me about**: Full-Stack Architecture, React Ecosystem, Rust Backend & UI/UX Engineering.
- 📫 **How to reach me**: [faizalazzriel@upi.edu](mailto:faizalazzriel@upi.edu)
